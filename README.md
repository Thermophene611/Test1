# 사주 보기

생년월일시를 넣으면 사주팔자(四柱八字)를 계산하고 간단한 풀이를 보여주는 웹앱입니다.
서버 없이 브라우저에서만 동작합니다.

## 기능

- 양력/음력(윤달 포함) 입력, 태어난 시간 모름 지원
- 한국 표준시 보정(−30분), 1987·1988년 서머타임 자동 보정
- 사주 원국: 천간·지지, 십신, 지장간, 12운성
- 일간(나를 나타내는 글자) 성격 풀이
- 오행 분포와 조언
- 올해 운세(세운), 10년 단위 대운 흐름

## 실행

`index.html`을 브라우저로 열면 됩니다. GitHub Pages로 배포하면 휴대폰에서도 바로 쓸 수 있습니다.

## 파일 구성

- `index.html` – 화면
- `style.css` – 디자인
- `app.js` – 입력 처리, 사주 계산, 결과 표시
- `saju-data.js` – 한글 표기와 풀이 문구
- `vendor/lunar.js` – 만세력 계산 라이브러리 ([lunar-javascript](https://github.com/6tail/lunar-javascript), MIT)
